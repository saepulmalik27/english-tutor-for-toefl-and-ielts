# 08: Speaking Error Patterns and tappable transcript

**What to build:** Speaking Feedback tags mistakes in the transcript with Error Pattern IDs. The Learner taps a highlighted phrase to see the pattern name, the correction and an Indonesian explanation, as in prototype variant A. Speaking patterns create or update FSRS cards the same way Reading ones do.

- [ ] Tapping a highlighted segment shows pattern name, correction and explanation
